# Personal Portfolio Website

A modern, responsive personal portfolio website built with React and Vite.

The purpose of this project is to present my background, technical skills, education and software development projects in a professional and accessible format.

## Overview

The portfolio is designed as a single-page website with reusable React components, responsive layouts and a consistent visual design.

## Features

- Responsive design for desktop, tablet and mobile.
- Navigation between portfolio sections.
- Personal introduction and About Me section.
- Skills and technologies overview.
- Project showcase with reusable project cards.
- Education and practical development experience.
- Contact information and social links.
- Responsive mobile navigation.

## Projects

The portfolio showcases the following projects:

- **MoneyFlow** – Personal finance management application.
- **Asset Tracking System** – IT asset management application.
- **Product List Manager** – Product management application.
- **AbraIlkDigital** – Digital agency website project (in progress).

## Installation and Setup

### Prerequisites

- Node.js
- npm
- Git

### Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Navigate into the project

```bash
cd PersonalPortfolio
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Create a production build

```bash
npm run build
```

### Run code quality checks

```bash
npm run lint
```
